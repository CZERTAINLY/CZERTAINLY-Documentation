# Introduction

The platform provides digital signing capabilities built on its own native building blocks. The currently available capability is **timestamping**.

The established SignServer-based implementation is also supported. Both implementations are documented here:

- **Native signing** — this section, built into the platform itself.
- **SignServer-based signing** — [Digital Signing — SignServer](/docs/signserver/introduction). The established implementation for production deployments.

:::tip
Timestamping is currently in preview and is not production-ready. Use the SignServer-based implementation for production deployments.
:::
