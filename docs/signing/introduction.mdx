# Introduction

Starting with release 2.19.0, ILM brings digital signing natively into the platform, built on ILM's native building blocks. Individual signing capabilities are delivered incrementally — **timestamping** is the first to land.

While ILM-native signing rolls out incrementally, the established SignServer-based implementation continues to be supported. Both are documented here:

- **ILM-native signing** — this section, built on ILM's native building blocks.
- **SignServer-based signing** — [Digital Signing — SignServer](/docs/signserver/introduction). The established implementation, supported throughout the transition.

:::tip
ILM-native timestamping is currently in preview and not yet production-ready, but is planned to reach production readiness in the next release. If you are planning a new digital signing deployment, we strongly recommend considering the ILM-native approach.
:::
