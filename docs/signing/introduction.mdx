# Introduction

Starting with release 2.19.0, ILM provides digital signing capabilities built on the platform's native building blocks. The currently available capability is **timestamping**.

The established SignServer-based implementation is also supported. Both implementations are documented here:

- **ILM-native signing** — this section, built on ILM's native building blocks.
- **SignServer-based signing** — [Digital Signing — SignServer](/docs/signserver/introduction). The established implementation for production deployments.

:::tip
ILM-native timestamping is currently in preview and is not production-ready. Use the SignServer-based implementation for production deployments.
:::
